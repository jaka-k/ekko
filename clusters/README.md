# Clusters

This directory contains Flux cluster configurations for each environment.

## Structure

- `production/` - Production cluster configuration
- `dev/` - Development cluster configuration

## Usage

Each cluster directory should contain:
- `flux-system/` - Flux system components (generated by Flux bootstrap)
- Kustomization resources that reference infrastructure and namespaces

Example:
```
clusters/
├── production/
│   ├── flux-system/
│   ├── infrastructure.yaml
│   └── namespaces.yaml
└── dev/
    ├── flux-system/
    ├── infrastructure.yaml
    └── namespaces.yaml
```

## Bootstrap

To bootstrap Flux on a cluster:

```bash
flux bootstrap git \
  --url=ssh://git@github.com/<org>/<repository> \
  --branch=master \
  --path=clusters/production
```

Replace `production` with `dev` for the development cluster.
